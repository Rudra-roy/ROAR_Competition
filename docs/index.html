    Run it yourself

    On a machine where the Monza CARLA server already runs natively (the organisers' Windows setup):

    1. Use Python 3.8: carla 0.9.12 has no wheels for later versions.
    2. Install ROAR_PY first (it provides roar_py_interface, carla and gymnasium), then this repo's packages: pip install -r requirements.txt.
    3. Start the Monza server, then run the unmodified starter runner:
    cd competition_code
python competition_runner.py
    1. Expected output: Solution finished in 318.3… seconds or 318.4… (318.30 to 318.40 s), and no major collision line.

    Two setups

    Linux with GE-Proton 9 is the setup we tested. Windows is the organisers' setup and was not tested by us. Both are written out step by step, with troubleshooting, in the README.
